Packages that add ready-made behavior on top of the core stores. Each page below is the plugin's own README.

- [Persistent](/docs/ecosystem/persistent/): keep a store in `localStorage` and sync it between browser tabs.
- [Query](/docs/ecosystem/query/): fetch data into stores with caching and revalidation.
- [Router](/docs/ecosystem/router/): keep the current URL and route params in stores.
- [I18n](/docs/ecosystem/i18n/): make an app translatable with stores and the JS Internationalization API.
- [Devtools](/docs/ecosystem/devtools/): inspect store state in the Redux DevTools extension.
